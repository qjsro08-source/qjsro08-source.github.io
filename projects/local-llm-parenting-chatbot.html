구조System

기기에 올릴 수 있는 크기로Small enough to run on the device

육아 상담은 수유·배변·발열 같은 아이의 민감한 기록을 그대로 다루고, 부모는 같은 상황을 하루에도 몇 번씩 되묻습니다. 그래서 답변 모델을 휴대기기에서 돌릴 수 있는 크기의 작은 LLM(Gemma 4 E4B, 4-bit 양자화)으로 잡았습니다. 기기 안에서 답을 만들면 아이 기록이 담긴 근거를 외부 API로 보낼 필요가 없고, 질문이 늘어도 비용이 늘지 않습니다.Parenting advice deals directly with a child's sensitive records, such as feeding, bowel movements and fever, and parents ask about the same situation several times a day. So the answer model is a small LLM sized to run on a handheld device (Gemma 4 E4B, 4-bit quantized). Generating answers on the device means evidence holding the child's records never goes to an external API, and cost does not grow with the number of questions.

질문이 들어오면 먼저 어떤 경로가 필요한지 분류하고, 필요하면 아이 기록과 전문자료를 찾아 답에 쓸 근거만 압축합니다. 답변 모델은 이 근거를 받아 정해진 네 부분으로 답하고, 문장마다 근거 ID를 답니다. 근거가 없는 판단은 하지 않고 정보 부족으로 표시한 뒤 되묻습니다.Each question is first classified by the path it needs; when needed, the child's records and the reference material are searched and compressed down to the evidence the answer will use. The answer model takes this evidence, answers in four fixed parts and tags each sentence with its source ID. It makes no judgment without evidence: it flags not enough info and asks back.

데이터와 학습Data and training

공개 QA에서 육아 질문만 골라 LoRA로 맞춘다Pick parenting questions from public QA and fit the model with LoRA

국내 공개 한국어 QA 데이터셋을 합친 뒤, 질문에 육아 관련 키워드(육아·이유식·수유·신생아·임신 등)가 들어간 것만 골랐습니다. ‘아이디’, ‘아이폰’처럼 키워드에 걸리지만 육아와 무관한 질문은 걸러내고, 공백·빈 값과 중복 질문을 제거해 육아 QA 427건을 만들었습니다.We merged public Korean QA datasets and kept only questions containing parenting keywords (parenting, baby food, feeding, newborn, pregnancy and so on). Questions that hit a keyword but have nothing to do with parenting, such as ‘아이디’ (user ID) and ‘아이폰’ (iPhone), which contain the Korean word for child, were filtered out, and blanks, empty values and duplicate questions were removed, leaving 427 parenting QA pairs.

  1. 통합Merged131,327국내 공개 한국어 QAPublic Korean QA
  2. 키워드 필터Keyword filter863질문에 육아 키워드 포함Parenting keyword in the question
  3. 오탐 제외False positives out468아이디·아이폰 같은 제외어 제거Excluded words such as 아이디 and 아이폰 removed
  4. 빈 값·중복 제거Blanks and duplicates out427육아 QA 데이터셋Parenting QA dataset

이 데이터로 Gemma 4 E4B를 LoRA로 튜닝했습니다. 답변 부분에만 학습 신호가 가도록 라벨을 구성해, 모델 전체가 아니라 작은 어댑터만 학습시켜 육아 도메인의 말투와 지식을 입혔습니다.With this data we tuned Gemma 4 E4B with LoRA. Labels were built so that only the answer part carries the training signal, and only a small adapter, not the whole model, was trained to give it the tone and knowledge of the parenting domain.

평가 설계Evaluation design

차이가 답변 모델에서만 나오도록So that differences come only from the answer model

같은 대화 10세트 38턴을 모델 5개로 돌렸습니다. 질문 분류·기록 조회·전문자료 검색·근거 압축은 GPT-5.6 Luna로 한 번만 실행해 고정하고 모든 모델에 똑같이 넣었으며, 이전 턴의 답변도 고정 대본으로 두어 모든 모델이 같은 대화 이력을 봅니다. 그래서 결과의 차이는 답변 모델에서 나옵니다. 아이는 10개월, 기록은 208건, 전문자료는 5종 467청크입니다.We ran the same 10 conversation sets, 38 turns, through 5 models. Question classification, record lookup, reference search and evidence compression were run once with GPT-5.6 Luna and fixed, then fed identically to every model, and earlier turns' answers were also fixed as a script so every model sees the same history. Differences in the results therefore come from the answer model. The child is 10 months old, with 208 records and 5 references in 467 chunks.
